# Violet

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文** | [日本語](README.ja.md) | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

Violet 是一個裝在你自己伺服器上的 AI 陪伴。她有穩定的個性和自己的日常，會記住你說過的事，會在適當的時候主動找你，在微信、QQ、Telegram 上都能和她聊。所有設定都在網頁後台完成，不需要修改設定檔。

> 靈感來源：[Lynnette177/Project-Eve](https://github.com/Lynnette177/Project-Eve)（作者 [Lynnette177](https://github.com/Lynnette177)）。Violet 在它的基礎上重寫並擴充了大部分功能，已經是一個獨立的專案。感謝原作者的創意。

後台介面目前是簡體中文。

## 她能做什麼

**聊天**

- 微信（ClawBot / iLink 掃碼）、QQ 小號（SnowLuma，掃碼登入）、QQ 官方機器人、Telegram，可以同時連好幾個。
- 只回覆綁定好的你；陌生人的私訊不回，也不保存原文。
- QQ 小號可以進群：有人叫她名字、@ 她或戳她時她會接話，冷場時偶爾自己起個話題；群裡的人她會慢慢認識。也能看群裡的圖片、收藏和傳送貼圖、在 QQ 空間發動態（發之前先給你看）。
- 一次可以傳好幾則訊息、傳語音（選用：用一段錄音複製聲音，在伺服器 CPU 上執行）、傳她畫的圖。

**記憶**

- 分開記住你的長期狀況、最近發生的事、你喜歡她怎麼說話、你們的約定。舊的事會慢慢淡去，沒說完的話不會被當成任務反覆追問。
- 後台「記憶」頁可以搜尋（關鍵字醒目提示）、查看、更正、刪除，或者禁止她使用某一條。
- 「明天八點提醒我交作業」會真的記下來，時間到了提醒你。

**人設與關係**

- 內建幾種人設：Violet（預設）、溫柔陪伴、元氣同學、冷靜可靠、知道自己是 AI 的、大肥魚、Eve 原版人設、空白人設，也可以自己寫一個。
- 關係可選：親近、朋友、戀人、女兒、開發者。
- 不同聊天管道可以用不同人設。每個人設有自己的一份聊天紀錄、記憶、生活和心情，切來切去都不會遺失，也不會混在一起。
- 她有自己的虛擬日常和心情：日子平淡地往前走，可能好幾天什麼都沒發生；被兇了會有小情緒。她不會捏造生活紀錄裡沒有的經歷。

**主動聯絡**

- 會主動分享、想你、接著之前的話題聊，也可能決定不傳。
- 有安靜時段、每日上限和「你沒回就先等等」的規則；你說「別一直找我」，她就會少找你。
- 選用：依你們的關係傳節日祝福（春節、中秋、你的生日；戀人還有情人節、七夕……）。
- 選用：連上手機後（見下方的 Violet MCP），她知道你現在螢幕亮著沒、在用哪個 App、電量、今天的螢幕使用時間，早上你第一次解鎖手機時可以跟你說早安。

**工具**（都是選用的，預設關閉，在後台開啟）

- 網路搜尋和讀網頁：後台一鍵安裝私有的 SearXNG，只在本機監聽，不需要 Docker。
- 課表：上課時不打擾你、考試前幫你加油。可以從 CSV / JSON 匯入。
- 看圖和畫圖：畫的是「手機隨手拍」風格的生活照，不會說成真實照片。
- MCP 工具：唯讀工具直接使用；會改動東西的工具每次都先問你，你在聊天裡同意後才執行。

**網頁後台**

- 開始（還差哪一步）、總覽、流程（每一輪回覆用了哪些提示詞、工具和模型，可以看到送給模型的完整內容）。
- 模型服務（每個 Agent、每個聊天平台可以用不同模型）、聊天管道、工具與手機、圖片、人設與生活、課表、設定。
- 聊天紀錄、記憶、診斷、日誌、修改紀錄、帳號安全。

**從 Project Eve 搬過來**

後台「聊天紀錄 → 匯入聊天紀錄和記憶」會給出一條打包指令，在 Eve 的伺服器上執行，再把產生的檔案上傳到後台。匯入時可以選擇匯入到哪個聊天管道（還沒新增的管道也可以）、用哪個人設、什麼關係，聊天紀錄和記憶都會一起帶過來。

## 安裝

在一台 Linux 伺服器上，一行指令：

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash
```

- Debian、Ubuntu、Rocky 等都用這一條。root 直接安裝（Debian 最小安裝沒有 sudo 也可以）；一般使用者會自動透過 sudo 執行；沒有 sudo 的一般使用者請先 `su -` 切換到 root。
- 安裝程式會裝好 Python 和相依套件、註冊 systemd 服務、隨機選一個連接埠，並像 1Panel 一樣產生隨機的安全入口、使用者名稱和初始密碼。最後會顯示後台網址，格式是 `https://伺服器IP:連接埠/安全入口`。
  - 憑證是自簽的，瀏覽器提示「不安全」時選擇繼續前往即可。
  - 雲端伺服器還要在主控台的「安全群組 / 防火牆」裡開放這個連接埠。
- 裝好以後：
  1. 開啟後台，在「開始」頁填寫模型服務的網址和 Key。
  2. 在「聊天管道」頁連上任一聊天平台，就可以開始聊天了。
- 忘記網址或使用者名稱用 `/opt/violet/violet info` 查看，忘記密碼用 `/opt/violet/violet reset-password` 重設。

**需求**：

- 一個與 OpenAI 相容的模型 API。
- 伺服器記憶體建議至少 512 MB。若要使用語音，需要 8 GB 記憶體、12 GB 硬碟。

**只想在伺服器本機存取**（透過 SSH 通道管理）：

- 新安裝：在安裝指令後面加上 `-s -- --access local`。
- 已經裝好的：重新執行一次安裝指令，帶上想要的存取方式（`local` / `lan` / `public` / `proxy`）。資料、帳號和連接埠都會保留。

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash -s -- --access local
```

更多說明（存取方式、防火牆、日常維護指令）見 [violet/INSTALL.zh-CN.md](violet/INSTALL.zh-CN.md)（簡體中文）。

## 更新

- 預設自動更新：有新版本就在伺服器上自動升級。升級前先備份，升級失敗自動退回舊版本。
- 也可以在後台「設定 → 版本更新」改成「只提醒」或「手動檢查」。
- 在後台「開始」頁點「立即更新」會顯示進度。
- 也可以在伺服器上手動升級：

```bash
/opt/violet/violet update
```

## 解除安裝

下面這一條指令會徹底刪除 Violet，**刪除後無法復原**：

- 程式、服務、自動更新和後台任務服務；
- 手機 MCP 中繼、網路搜尋、QQ 小號、語音；
- 設定、資料（聊天紀錄和記憶）和備份；
- `violet` 系統帳號、`/opt/violet` 目錄，以及 Violet 開放的所有防火牆規則。

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash -s -- uninstall --purge --yes
```

只裝了一半、安裝紀錄遺失，或之前只解除安裝了程式，這條指令也能把剩下的東西清乾淨。透過系統套件管理員安裝的 Python、openssl 不會刪除，因為其他程式可能也在用。

## 目前狀態

- **自動測試**：
  - 所有功能都有離線自動化測試，共約 3000 項，用模擬的模型和聊天平台執行，不連網。
  - 每次修改安裝程式，都會在 GitHub Actions 的真實 Linux 上（Ubuntu 22.04 / 24.04、Debian 12、Rocky Linux 9）把安裝、自動重啟、備份、升級失敗退回、解除安裝完整跑一遍。
- **實際使用**：
  - 四個聊天管道（微信、QQ 小號、QQ 官方機器人、Telegram）都在真實平台上測試過。
  - 從 Project Eve 匯入聊天紀錄和記憶，用真實資料匯入過。
  - QQ 小號的一鍵安裝在中國大陸網路下也安裝成功過。
- **關於她的身分**：這是一個陪伴類專案。Violet 清楚自己是虛構角色，不會冒充真人；AI 畫的圖不會說成真實照片。

## 儲存庫裡有什麼

| 路徑 | 內容 |
|---|---|
| `violet/ai/` | 她自己：聊天、記憶、人設、心情、虛擬生活、主動聯絡、群聊、工具、畫圖、課表 |
| `violet/ai/channels/` | 微信、QQ、Telegram 的連線 |
| `violet/wx_ilink_py/` | 網頁後台（Flask）和微信 iLink 用戶端 |
| `violet/persona/` | 人設範本和提示詞 |
| `violet/tools/` | 安裝程式、發布、選用元件（網路搜尋、QQ 小號、語音、手機中繼）的安裝腳本，以及開發用的測試工具 |
| `violet/tests/` | 離線自動化測試 |
| `violet/deploy/` | 安裝驗收腳本、用 Docker 部署 SearXNG 的另一種方式 |
