# Violet

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md) | **한국어** | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

Violet은 내 서버에서 직접 운영하는 AI 동반자입니다. 한결같은 성격과 자기만의 일상이 있고, 당신이 한 말을 기억하며, 적절한 때에 먼저 말을 걸어 옵니다. WeChat, QQ, Telegram에서 대화할 수 있습니다. 모든 설정은 웹 관리 화면에서 하며, 설정 파일을 직접 고칠 필요가 없습니다.

> 영감을 받은 프로젝트: [Lynnette177/Project-Eve](https://github.com/Lynnette177/Project-Eve)(제작자 [Lynnette177](https://github.com/Lynnette177)). Violet은 그 대부분을 새로 쓰고 확장했으며, 지금은 독립된 프로젝트입니다. 아이디어를 준 원작자에게 감사드립니다.

관리 화면은 현재 중국어입니다.

## 할 수 있는 일

**채팅**

- WeChat(ClawBot / iLink, QR 코드 스캔), QQ 개인 계정(SnowLuma, 스캔으로 로그인), QQ 공식 봇, Telegram. 여러 개를 동시에 연결할 수 있습니다.
- 연결해 둔 당신에게만 답합니다. 모르는 사람의 개인 메시지에는 답하지 않고, 내용도 저장하지 않습니다.
- QQ 개인 계정이라면 그룹에도 들어갈 수 있습니다. 누가 이름을 부르거나 @하거나 콕 찌르면 대화에 끼고, 조용할 때는 가끔 먼저 화제를 꺼냅니다. 그룹 사람들도 조금씩 알아 갑니다. 그룹의 이미지를 보고, 스티커를 모아서 보내고, QQ 공간에 글을 올릴 수도 있습니다(올리기 전에 먼저 보여 줍니다).
- 한 번에 여러 개의 메시지, 음성 메시지(선택: 녹음 하나로 목소리를 복제, 서버 CPU에서 실행), 직접 그린 그림을 보낼 수 있습니다.

**기억**

- 당신의 장기적인 상황, 최근 일어난 일, 당신이 좋아하는 말투, 두 사람의 약속을 따로 기억합니다. 오래된 일은 천천히 희미해지고, 하다 만 말이 할 일처럼 되풀이해서 캐물어지지는 않습니다.
- 관리 화면의 "기억" 페이지에서 검색(키워드 강조), 보기, 수정, 삭제하거나 특정 기억을 쓰지 못하게 할 수 있습니다.
- "내일 8시에 숙제 내라고 알려 줘"라고 하면 정말로 기록해 두었다가 제시간에 알려 줍니다.

**페르소나와 관계**

- 기본 페르소나: Violet(기본값), 다정한 동반자, 활기찬 동기, 차분하고 믿음직한 사람, 자신이 AI인 걸 아는 아이, 대비어(빅 팻 피시), Eve 원래 페르소나, 빈 페르소나. 직접 써도 됩니다.
- 관계는 가까운 사이, 친구, 연인, 딸, 개발자 중에서 고를 수 있습니다.
- 채팅 채널마다 다른 페르소나를 쓸 수 있습니다. 페르소나마다 채팅 기록, 기억, 생활, 기분이 따로 있어서 이리저리 바꿔도 잃어버리거나 섞이지 않습니다.
- 그녀에게는 가상의 일상과 기분이 있습니다. 하루하루가 잔잔히 흘러가고, 며칠 동안 아무 일도 없을 수도 있습니다. 모질게 대하면 살짝 토라집니다. 생활 기록에 없는 경험을 지어내지 않습니다.

**먼저 연락하기**

- 무언가를 나누거나, 보고 싶다고 하거나, 전에 하던 이야기를 이어 가거나, 보내지 않기로 하기도 합니다.
- 조용한 시간대, 하루 상한, "답장이 없으면 일단 기다리기" 규칙이 있습니다. "너무 자주 연락하지 마"라고 하면 연락을 줄입니다.
- 선택: 관계에 맞는 명절 인사(설날, 중추절, 당신의 생일, 연인이라면 밸런타인데이, 칠석 등).
- 선택: 휴대폰을 연결하면(아래 Violet MCP 참고) 화면이 켜져 있는지, 어떤 앱을 쓰고 있는지, 배터리 잔량, 오늘의 화면 사용 시간을 알 수 있고, 아침에 처음 휴대폰 잠금을 풀 때 "좋은 아침"이라고 인사할 수 있습니다.

**도구**(모두 선택 사항이며 기본값은 꺼짐, 관리 화면에서 켭니다)

- 웹 검색과 페이지 읽기: 관리 화면에서 개인용 SearXNG를 원클릭으로 설치합니다. 서버 자체에서만 수신하며 Docker가 필요 없습니다.
- 시간표: 수업 중에는 방해하지 않고 시험 전에는 응원해 줍니다. CSV / JSON에서 가져올 수 있습니다.
- 이미지 보기와 그리기: "폰으로 대충 찍은" 느낌의 일상 사진을 그리며, 진짜 사진이라고 말하지 않습니다.
- MCP 도구: 읽기 전용 도구는 바로 씁니다. 무언가를 바꾸는 도구는 매번 먼저 묻고, 채팅에서 당신이 승인한 뒤에만 실행합니다.

**웹 관리 화면**

- 시작(아직 남은 단계), 개요, 흐름(각 답장에 어떤 프롬프트, 도구, 모델이 쓰였는지, 모델에 보낸 전체 내용을 볼 수 있습니다).
- 모델 서비스(에이전트별, 채팅 플랫폼별로 다른 모델 사용 가능), 채팅 채널, 도구와 휴대폰, 이미지, 페르소나와 생활, 시간표, 설정.
- 채팅 기록, 기억, 진단, 로그, 변경 기록, 계정 보안.

**Project Eve에서 옮겨 오기**

관리 화면의 "채팅 기록 → 채팅 기록과 기억 가져오기"에 패키징 명령이 나옵니다. Eve 서버에서 실행한 뒤 생성된 파일을 관리 화면에 올리면 됩니다. 가져올 때 어느 채팅 채널(아직 추가하지 않은 채널도 가능), 어떤 페르소나, 어떤 관계로 할지 고를 수 있고, 채팅 기록과 기억이 모두 넘어옵니다.

## 설치

Linux 서버에서 명령 한 줄이면 됩니다:

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash
```

- Debian, Ubuntu, Rocky 등 모두 이 한 줄이면 됩니다. root라면 바로 설치합니다(sudo가 없는 최소 설치 Debian도 가능). 일반 사용자라면 자동으로 sudo를 통해 다시 실행합니다. sudo가 없는 일반 사용자는 먼저 `su -`로 root로 전환하세요.
- 설치 프로그램은 Python과 의존성을 설치하고, systemd 서비스를 등록하고, 무작위 포트를 고르고, 1Panel처럼 무작위 보안 입구, 사용자 이름, 초기 비밀번호를 만듭니다. 마지막에 관리 화면 주소를 `https://서버IP:포트/입구` 형식으로 보여 줍니다.
  - 인증서는 자체 서명입니다. 브라우저가 "안전하지 않음"이라고 하면 계속 진행을 선택하세요.
  - 클라우드 서버라면 콘솔의 보안 그룹 / 방화벽에서도 이 포트를 열어야 합니다.
- 설치 후:
  1. 관리 화면을 열고 "시작" 페이지에서 모델 서비스 주소와 키를 입력합니다.
  2. "채팅 채널" 페이지에서 아무 채팅 플랫폼이나 연결하면 대화를 시작할 수 있습니다.
- 주소나 사용자 이름을 잊었다면 `/opt/violet/violet info`, 비밀번호를 잊었다면 `/opt/violet/violet reset-password`로 재설정합니다.

**필요한 것**:

- OpenAI 호환 모델 API.
- 메모리 512 MB 이상 권장. 음성을 쓰려면 메모리 8 GB, 디스크 12 GB가 필요합니다.

**서버 자체에서만 관리 화면에 접속하기**(SSH 터널로 관리):

- 새로 설치: 설치 명령 뒤에 `-s -- --access local`을 붙입니다.
- 이미 설치함: 원하는 접근 방식(`local` / `lan` / `public` / `proxy`)을 붙여 설치 명령을 다시 실행합니다. 데이터, 계정, 포트는 유지됩니다.

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash -s -- --access local
```

자세한 설명(접근 방식, 방화벽, 일상 유지 관리 명령)은 [violet/INSTALL.md](violet/INSTALL.md)(영어)를 참고하세요.

## 업데이트

- 기본값은 자동 업데이트입니다. 새 버전이 나오면 서버가 스스로 업그레이드합니다. 먼저 백업하고, 업그레이드에 실패하면 자동으로 이전 버전으로 되돌립니다.
- 관리 화면의 "설정 → 버전 업데이트"에서 "알림만" 또는 "수동 확인"으로 바꿀 수 있습니다.
- "시작" 페이지에서 "지금 업데이트"를 누르면 진행 상황이 표시됩니다.
- 서버에서 직접 업그레이드할 수도 있습니다:

```bash
/opt/violet/violet update
```

## 제거

아래 명령은 Violet을 완전히 삭제합니다. **되돌릴 수 없습니다.** 삭제되는 것:

- 프로그램, 서비스, 자동 업데이트, 백그라운드 작업 서비스
- 휴대폰 MCP 릴레이, 웹 검색, QQ 계정, 음성
- 설정, 데이터(채팅 기록과 기억), 백업
- `violet` 시스템 계정, `/opt/violet` 디렉터리, Violet이 연 모든 방화벽 규칙

```bash
curl -fsSL https://github.com/aileboeth/violet-companion/releases/latest/download/install.sh | bash -s -- uninstall --purge --yes
```

설치가 중간에 멈췄거나, 설치 기록을 잃어버렸거나, 예전에 프로그램만 제거한 경우에도 이 명령으로 남은 것을 깨끗이 정리할 수 있습니다. 시스템 패키지 관리자로 설치한 Python과 openssl은 다른 프로그램도 쓸 수 있으므로 삭제하지 않습니다.

## 현재 상태

- **자동 테스트**:
  - 모든 기능에 오프라인 자동 테스트가 있으며 모두 약 3000개입니다. 시뮬레이션 모델과 채팅 플랫폼으로, 네트워크 없이 실행합니다.
  - 설치 프로그램이 바뀔 때마다 GitHub Actions의 실제 Linux(Ubuntu 22.04 / 24.04, Debian 12, Rocky Linux 9)에서 설치, 자동 재시작, 백업, 업그레이드 실패 시 롤백, 제거를 처음부터 끝까지 실행합니다.
- **실제 사용**:
  - 채팅 채널 네 개(WeChat, QQ 개인 계정, QQ 공식 봇, Telegram) 모두 실제 플랫폼에서 테스트했습니다.
  - Project Eve에서 채팅 기록과 기억을 가져오는 기능은 실제 데이터로 해 보았습니다.
  - QQ 개인 계정 원클릭 설치는 중국 본토 네트워크에서도 성공했습니다.
- **그녀가 누구인지에 대해**: 이것은 동반자 프로젝트입니다. Violet은 자신이 가상의 캐릭터라는 것을 알고 있으며 실제 사람인 척하지 않습니다. AI가 그린 그림을 진짜 사진이라고 속이지도 않습니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `violet/ai/` | Violet 자신: 채팅, 기억, 페르소나, 기분, 가상 생활, 먼저 연락하기, 그룹 채팅, 도구, 그림, 시간표 |
| `violet/ai/channels/` | WeChat, QQ, Telegram 연결 |
| `violet/wx_ilink_py/` | 웹 관리 화면(Flask)과 WeChat iLink 클라이언트 |
| `violet/persona/` | 페르소나 템플릿과 프롬프트 |
| `violet/tools/` | 설치 프로그램, 릴리스, 선택 구성 요소(웹 검색, QQ 계정, 음성, 휴대폰 릴레이) 설치 스크립트, 개발용 테스트 도구 |
| `violet/tests/` | 오프라인 자동 테스트 |
| `violet/deploy/` | 설치 검수 스크립트, Docker로 SearXNG를 배포하는 다른 방법 |

## 관련 프로젝트

[Violet MCP](https://github.com/aileboeth/violet-mcp)는 선택 사항인 Android 앱입니다. 휴대폰에 설치하면 당신이 허락한 범위 안에서 화면이 켜져 있는지, 쓰고 있는 앱, 배터리, 걸음 수, 캘린더, 재생 중인 음악 같은 휴대폰 상태를 Violet이 알 수 있습니다. 항목마다 휴대폰에서 따로 켜고 끌 수 있습니다.
