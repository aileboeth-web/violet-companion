# Violet

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Русский](README.ru.md) | [Português](README.pt-BR.md)

Violet は、自分のサーバーで動かす AI コンパニオンです。安定した性格と自分なりの日常を持ち、あなたが話したことを覚えていて、ちょうどいいタイミングで自分から話しかけてきます。WeChat、QQ、Telegram で話せます。設定はすべて Web 管理画面で行い、設定ファイルを編集する必要はありません。

> 着想元：[Lynnette177/Project-Eve](https://github.com/Lynnette177/Project-Eve)（作者 [Lynnette177](https://github.com/Lynnette177)）。Violet はその大部分を書き直し・拡張しており、現在は独立したプロジェクトです。原作者のアイデアに感謝します。

管理画面は現在中国語です。

## できること

**チャット**

- WeChat（ClawBot / iLink、QR コードをスキャン）、QQ の個人アカウント（SnowLuma、スキャンでログイン）、QQ 公式ボット、Telegram。複数を同時に接続できます。
- 返信するのは紐づけたあなただけです。知らない人からの個別メッセージには返信せず、本文も保存しません。
- QQ の個人アカウントならグループにも参加できます。名前を呼ばれたり、@ されたり、つつかれたりすると会話に加わり、場が静かなときはたまに自分から話題を出します。グループのメンバーのことも少しずつ覚えていきます。グループの画像を見たり、スタンプを集めて送ったり、QQ 空間に投稿したり（投稿前にあなたに見せます）もできます。
- 一度に複数のメッセージ、音声メッセージ（オプション：1 本の録音から声をクローン、サーバーの CPU で動作）、自分で描いた絵を送れます。

**記憶**

- あなたの長期的な状況、最近の出来事、話し方の好み、二人の約束を分けて覚えます。古いことは少しずつ薄れていき、言いかけただけの話がタスクとして何度も問い詰められることはありません。
- 管理画面の「記憶」ページで検索（キーワードをハイライト）、閲覧、修正、削除したり、特定の記憶を使わせないようにしたりできます。
- 「明日の 8 時に宿題の提出をリマインドして」と言えば本当に記録され、時間どおりに知らせてくれます。

**ペルソナと関係**

- 組み込みのペルソナ：Violet（デフォルト）、やさしい寄り添い役、元気なクラスメイト、冷静で頼れる人、自分が AI だと分かっている子、大肥魚（ビッグ・ファット・フィッシュ）、Eve オリジナルのペルソナ、空白のペルソナ。自分で書くこともできます。
- 関係は「親しい」「友達」「恋人」「娘」「開発者」から選べます。
- チャットチャネルごとに別のペルソナを使えます。ペルソナごとにチャット履歴・記憶・生活・気分が別々にあるので、切り替えても何も失われず、混ざることもありません。
- 彼女には仮想の日常と気分があります。日々は穏やかに過ぎ、何日も何も起こらないこともあります。きつく当たられると少し拗ねます。生活記録にない経験をでっち上げることはありません。

**自分から連絡する**

- 何かを共有したり、会いたいと言ったり、前の話題の続きをしたり、送らないと決めたりします。
- 静かな時間帯、1 日の上限、「返事がなければ待つ」ルールがあります。「あまり連絡してこないで」と言えば、連絡を減らします。
- オプション：関係に合わせた季節の挨拶（春節、中秋節、あなたの誕生日。恋人ならバレンタインデー、七夕なども）。
- オプション：スマートフォンを接続すると（下の Violet MCP を参照）、画面がついているか、どのアプリを使っているか、バッテリー残量、今日の画面使用時間が分かり、朝はじめてスマホのロックを解除したときに「おはよう」と言えます。

**ツール**（すべてオプションで、デフォルトはオフ。管理画面でオンにします）

- Web 検索とページの閲覧：プライベートな SearXNG を管理画面からワンクリックでインストール。サーバー自身でのみ待ち受け、Docker は不要です。
- 時間割：授業中は邪魔をせず、試験前には応援してくれます。CSV / JSON からインポートできます。
- 画像を見る・描く：描くのは「スマホで気軽に撮った」風の日常写真で、本物の写真だと言うことはありません。
- MCP ツール：読み取り専用のツールはそのまま使います。何かを変更するツールは毎回まずあなたに確認し、チャットであなたが承認してから実行します。

**Web 管理画面**

- スタート（あと何が足りないか）、概要、フロー（各返信でどのプロンプト・ツール・モデルが使われたか。モデルに送った内容をすべて確認できます）。
- モデルサービス（エージェントごと、チャットプラットフォームごとに別のモデルを使えます）、チャットチャネル、ツールとスマホ、画像、ペルソナと生活、時間割、設定。
- チャット履歴、記憶、診断、ログ、変更履歴、アカウントのセキュリティ。

**Project Eve からの移行**

管理画面の「チャット履歴 → チャット履歴と記憶のインポート」にパッケージ作成コマンドが表示されます。それを Eve のサーバーで実行し、生成されたファイルを管理画面にアップロードします。インポート時に、どのチャットチャネル（まだ追加していないチャネルでも可）、どのペルソナ、どの関係にするかを選べ、チャット履歴と記憶の両方が引き継がれます。

## インストール

Linux サーバーで、コマンド 1 行です：

```bash
curl -fsSL https://github.com/aileboeth-web/violet-companion/releases/latest/download/install.sh | bash
```

- Debian、Ubuntu、Rocky などすべてこの 1 行で OK です。root ならそのままインストールします（sudo のない最小構成の Debian でも可）。一般ユーザーなら自動的に sudo 経由で実行し直します。sudo のない一般ユーザーは、先に `su -` で root に切り替えてください。
- インストーラーは Python と依存パッケージを入れ、systemd サービスを登録し、ランダムなポートを選び、1Panel と同様にランダムなセキュリティエントランス・ユーザー名・初期パスワードを生成します。最後に管理画面のアドレスを `https://サーバーIP:ポート/エントランス` の形式で表示します。
  - 証明書は自己署名です。ブラウザに「安全ではありません」と表示されたら、そのまま続行してください。
  - クラウドサーバーの場合は、コンソールのセキュリティグループ / ファイアウォールでもこのポートを開放してください。
- インストール後：
  1. 管理画面を開き、「スタート」ページでモデルサービスのアドレスとキーを入力します。
  2. 「チャットチャネル」ページで好きなチャットプラットフォームを接続すれば、チャットを始められます。
- アドレスやユーザー名を忘れたら `/opt/violet/violet info`、パスワードを忘れたら `/opt/violet/violet reset-password` で再設定できます。

**必要なもの**：

- OpenAI 互換のモデル API。
- メモリは 512 MB 以上を推奨。音声を使う場合はメモリ 8 GB、ディスク 12 GB が必要です。

**管理画面をサーバー自身からのみ開けるようにする**（SSH トンネル経由で管理）：

- 新規インストール：インストールコマンドの後ろに `-s -- --access local` を付けます。
- インストール済み：希望するアクセス方式（`local` / `lan` / `public` / `proxy`）を付けて、インストールコマンドをもう一度実行します。データ、アカウント、ポートは保持されます。

```bash
curl -fsSL https://github.com/aileboeth-web/violet-companion/releases/latest/download/install.sh | bash -s -- --access local
```

詳しい説明（アクセス方式、ファイアウォール、日常のメンテナンスコマンド）は [violet/INSTALL.md](violet/INSTALL.md)（英語）を参照してください。

## アップデート

- デフォルトは自動アップデートです。新しいバージョンが出るとサーバーが自動でアップグレードします。事前にバックアップを取り、失敗したら自動で旧バージョンに戻します。
- 管理画面の「設定 → バージョン更新」で「通知のみ」または「手動で確認」に変更できます。
- 「スタート」ページで「今すぐ更新」をクリックすると進捗が表示されます。
- サーバー上で手動アップグレードもできます：

```bash
/opt/violet/violet update
```

## アンインストール

次のコマンドで Violet を完全に削除します。**元には戻せません。** 削除されるもの：

- プログラム、サービス、自動アップデート、バックグラウンドタスクサービス
- スマホ用 MCP リレー、Web 検索、QQ アカウント、音声
- 設定、データ（チャット履歴と記憶）、バックアップ
- `violet` システムアカウント、`/opt/violet` ディレクトリ、Violet が開放したすべてのファイアウォールルール

```bash
curl -fsSL https://github.com/aileboeth-web/violet-companion/releases/latest/download/install.sh | bash -s -- uninstall --purge --yes
```

インストールが途中で止まった場合、インストール記録が失われた場合、以前にプログラムだけをアンインストールした場合でも、残ったものをこのコマンドで片付けられます。システムのパッケージマネージャーで入れた Python と openssl は、他のプログラムも使っている可能性があるため削除しません。

## 現在の状況

- **自動テスト**：
  - すべての機能にオフラインの自動テストがあり、合計約 3000 件です。シミュレーションのモデルとチャットプラットフォームで、ネットワークなしで実行します。
  - インストーラーを変更するたびに、GitHub Actions 上の実際の Linux（Ubuntu 22.04 / 24.04、Debian 12、Rocky Linux 9）で、インストール、自動再起動、バックアップ、アップグレード失敗時のロールバック、アンインストールを一通り実行します。
- **実際の利用**：
  - 4 つのチャットチャネル（WeChat、QQ 個人アカウント、QQ 公式ボット、Telegram）はすべて実際のプラットフォームでテスト済みです。
  - Project Eve からのチャット履歴と記憶のインポートは、実データで行いました。
  - QQ 個人アカウントのワンクリックインストールは、中国本土のネットワークでも成功しています。
- **彼女が何者かについて**：これはコンパニオン系のプロジェクトです。Violet は自分が架空のキャラクターだと分かっていて、本物の人間のふりはしません。AI が描いた画像を本物の写真だと偽ることもありません。

## 関連プロジェクト

[Violet MCP](https://github.com/aileboeth-web/violet-mcp) はオプションの Android アプリです。スマホに入れると、あなたが許可した範囲で、画面がついているか、使っているアプリ、バッテリー、歩数、カレンダー、再生中の音楽などのスマホの状態を Violet が知ることができます。項目ごとにスマホ上で個別にオン・オフできます。
